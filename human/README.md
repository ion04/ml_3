# Документы для проверки человеком

PDF собираются из файлов проекта командой `.venv/bin/python -m src.human_docs` (нужен Google Chrome). Руками в них ничего не вписано. После изменения данных пересоберите: например, `... -m src.human_docs 07` пересоберёт только лист проверки.

| Файл | Что внутри | Что сделать |
|---|---|---|
| 01_сверка_с_заданием | Каждый пункт задания → статус и где выполнено | Прочитать; открытые пункты помечены 🧑 и ⚠️ |
| 02_банк_задач | 38 задач + 5 dev: условие RU/EN, эталон, рубрика, код расчёта эталона, заметки | Решить сами, отметить галочки, замечания — на полях |
| 03_гипотезы | H1, H6, H9 как закоммичены, коммит и время, справка | Знать обоснование прогноза к защите |
| 04_модели_промпт_прогоны | Модели и версии, даты, промпт целиком, число вызовов, железо | Для раздела «Методика» |
| 05_тип_E_AI4I | Датасет, удалённые утечки, разбиение, пример запроса, метрики | Для раздела «Методика» и типа E |
| 06_инструкция_проверяющим | Правила слепой проверки и чек-лист D | Прочитать обоим проверяющим до оценки |
| 07_лист_слепой_проверки | 80 ответов B, C, D без названий моделей | Читать здесь, оценки вносить в `grading/sheet_r1.csv` / `sheet_r2.csv` |
| 08_проверка_парсера | 20 автопроверенных ответов | «да / нет» → `grading/parser_spotcheck.csv` |
| 09_тарифы | Цены моделей с источниками | Сверить, поставить `verified_by_human` в `config/pricing.json` |
| 10_план_для_человека | HUMAN_TODO целиком | Что осталось сделать |
| 11_каркас_отчёта | Отчёт, вопросы самоконтроля, план доклада; жёлтые блоки — места для вашего текста | Заполнить после анализа |
