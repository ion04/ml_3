# ЛР3: Можно ли доверять LLM в задачах классического ML

Учебный проект студента, курс «Методы машинного обучения». Задание лежит в `ЛР LLM и AutoML.pdf`, стр. 1–9. ЛР4 (AutoML) не делаем.
- План: `PLAN.md`.
- Задачи для человека: `HUMAN_TODO.md`.
- Агентский флоу: `flow/README.md`.

## Правила преподавателя (можно нарушать по запросу)
- **Никаких выдуманных результатов.** Каждое число в отчёте считается в `analysis.ipynb` по логам. Числа руками не вписывать.
- Эталонные ответы задач. Твои черновики помечай `reference_status: "agent_draft"`.
- Ручную проверку типов B (обоснование), C и D делают **два человека вслепую**.
- Ответы LLM пишутся в `logs/calls.jsonl` сразу при получении. Файл только дописывается: не удалять, не переписывать, не «чистить».
- **Не перезапрашивать модель, чтобы получить ответ получше.** Повторный вызов допустим только при технической ошибке (сеть, 429, 5xx), и это должно быть видно в логе.
- Промпт отлаживается только на `data/tasks_dev.jsonl`. Подгонять его под одну модель нельзя.
- Гипотезы и прогноз коммитятся **до** оценочных прогонов.
- Воспроизводимость: фиксированные `random_state` и seed, `requirements.txt`, точные идентификаторы моделей и даты вызовов.
- На защите студента попросят объяснить любую строку кода. Поэтому код пиши простым, без лишних абстракций, с короткими комментариями там, где логика неочевидна.

## Демо-данные и отсутствие ключей
- Пока ключей API нет, код проверяется на mock-провайдере. Всё, что получено на mock или синтетике, пишется **только** в `demo/` (он в `.gitignore`): `demo/calls.jsonl`, `demo/results/` и т. п.
- В `logs/`, `results/`, `grading/` и `report/` попадают только реальные данные. Демо-числа нигде не должны выглядеть как результаты эксперимента.

## Технические соглашения
- Python: `.venv/bin/python`. Модули запускаются так: `.venv/bin/python -m src.<module>`.
- Секреты только в `.env` (он в `.gitignore`). Ключи никогда не печатать и не логировать.
- Любой вызов LLM идёт только через `src/llm.py::ask`.
- Модели и их параметры: `config/models.json`. Настройки эксперимента и выбранные гипотезы: `config/experiment.json`.
- Где что лежит:
  - производные результаты: `results/`;
  - листы ручной проверки: `grading/`;
  - рисунки: `report/figures/`.
- Git: коммиты только локальные, без push. `.env` не коммитить.
- Тексты, предназначенные человеку, пишутся на русском.
