# Гипотезы и прогноз (фиксируется коммитом ДО оценочных прогонов)

Заполняет команда (человек). Справка по всем 13 гипотезам: `docs/hypotheses_guide.md`.

Порядок:
1. Выбрать 3 гипотезы из **разных групп** (1: H1–H3; 2: H4–H7; 3: H8–H11; 4: H12–H13).
2. Заполнить три раздела ниже. Все строки с `TODO(человек)` заменить своим текстом, **на той же строке** после двоеточия; строки полей не удалять. Строка «Прогноз» должна начинаться со слов «подтвердится» или «не подтвердится».
3. Вписать ID в `config/experiment.json` → `"hypotheses"`, например `["H1", "H6", "H9"]`.
4. Проверить: `.venv/bin/python -m src.checks g1` (раздел про гипотезы).
5. Закоммитить: `git add hypotheses.md config/experiment.json && git commit -m "Гипотезы и прогноз до эксперимента"`.
   Хэш коммита для отчёта: `.venv/bin/python -m src.checks hypcommit`.
   После коммита файл не менять (в том числе `git commit --amend`): G1 берёт **последний** коммит, изменивший `hypotheses.md`,
   и требует, чтобы в журнале не было оценочных вызовов раньше него. Новый коммит после прогонов сделает их «ранними».
