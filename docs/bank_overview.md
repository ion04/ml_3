**C6** · C · pca · свои · сложность 2  
На промышленном предприятии система мониторинга собирает данные с 50 датчиков, установленных на производственном оборудовании. Датчики измеряют температуру, давление, вибрацию и энергопотребление. Накоплено 120 000 наблюдений, каждое описывается 50 числовыми признаками с разными единицами измерения. Предварительный анализ показал сильную корреляцию между многими признаками. Требуется уменьшить размерность данных для сокращения объёма хранения и ускорения последующего анализа, сохранив не менее 95% общей дисперсии. Меток классов нет. Физическая интерпретируемость каждого нового признака не обязательна, но важно минимизировать потери информации. Преобразование новых наблюдений должно выполняться быстро, а хранение преобразованных данных должно требовать меньше памяти. Какой метод выбрать и почему?  
→ *Эталон:* Метод главных компонент (PCA) после стандартизации числовых признаков. PCA строит ортогональные линейные комбинации исходных признаков, максимизирующие сохраняемую дисперсию. При сильной корреляции позволяет сократить размерность за счёт избыточной информации. Число компонент выбирается по накопленной доле объяснённой дисперсии не менее 95%. Стандартизация необходима из-за разных масштабов измерений. PCA не требует меток классов. Преобразование обучается на обучающей выборке и затем применяется к новым данным. Ограничения: ухудшение интерпретируемости признаков и потеря части информации; сохранение дисперсии не гарантирует сохранения всей информации, полезной для последующих задач.
