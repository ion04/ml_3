# Проверка воспроизводимости

Требование задания: каждое число отчёта должно воспроизводиться из ноутбука; фиксируются `random_state`, версии библиотек (`requirements.txt`), даты вызовов API и точные версии моделей.

## Что обеспечивает воспроизводимость

- Ответы моделей сохраняются в `logs/calls.jsonl` сразу при получении. Повторный запуск прогонов берёт ответ из журнала (кэш) и API не вызывает, поэтому числа не зависят от того, что модель ответила бы сегодня.
- Ноутбук `analysis.ipynb` читает только `results/`, `grading/`, `logs/`, `config/`. Бутстреп, выборка парсера, разбиение типа E и классические модели используют фиксированный seed из `config/experiment.json`.
- Окружение: Python 3.12.14, все пакеты с точными версиями в `requirements.txt` (`pip freeze`). Отпечаток `requirements.txt`, версии ключевых пакетов, `model_reported` и даты вызовов записаны в `results/run_manifest.json`.
- `results/summary_metrics.json` не содержит меток времени, поэтому два выполнения ноутбука на тех же входах дают побайтно один и тот же файл. Отпечатки входных файлов — в его ключе `inputs`.

## Процедура

```bash
scripts/check_reproducibility.sh          # реальные данные (после scripts/run_analysis.sh)
scripts/check_reproducibility.sh --demo   # на demo/ — проверка самой процедуры, не результатов
```

Что делает скрипт:
1. копирует проект во временную папку без `.venv`, `.env` и служебных файлов флоу и убирает из копии `summary_metrics.json`;
2. создаёт там новое окружение Python 3.12 из `requirements.txt` (`uv venv --seed --python 3.12` + `uv pip install -r`, без uv — `python3.12 -m venv` + pip);
3. выполняет `analysis.ipynb` целиком (`scripts/run_analysis.sh` копии, то есть Restart & Run All через nbconvert) ядром нового окружения;
4. сравнивает новый `summary_metrics.json` с исходным побайтно и по ключам верхнего уровня.

Код выхода: 0 — совпало, 1 — различается (печатаются ключи), 2 — нечего проверять, 3 — ноутбук в копии не выполнился. Файлы проекта не меняются, копия остаётся во временной папке для разбора.

## Чего проверка не покрывает

- Повторные вызовы API: модели не перезапрашиваются (это запрещено правилами работы и бессмысленно — ответ мог бы измениться). Воспроизводится всё, что получено из сохранённых ответов.
- Рисунки (`report/figures/*.png`) побайтно не сравниваются: в PNG могут отличаться метаданные. Они строятся из тех же таблиц, что и JSON.
- Другая ОС или архитектура процессора: проверка выполнена на той же машине (macOS arm64), только в чистом окружении.
