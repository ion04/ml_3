# Агентский флоу ЛР3

Работа разбита на 12 агентских шагов и 3 гейта человека. Каждый шаг выполняет **отдельная сессия Claude Code**: `claude-opus-5-5`, `--effort high`, `--dangerously-skip-permissions`. По умолчанию сессия открывается в новом окне Terminal.

## Как передаётся контекст
- **Handoff.** В конце шага агент пишет `flow/context/<шаг>.md`: статус, что сделано, файлы, решения, риски. Следующие шаги получают в промпте все предыдущие handoff.
- **`CLAUDE.md`** загружается в каждую сессию автоматически. Там правила преподавателя и соглашения проекта.
- **Память (auto-memory).** Агенты сохраняют в неё устойчивые факты, например особенности API провайдеров.
- **`flow/HUMAN_NOTES.md`.** Ваши решения и пожелания; файл целиком попадает в каждый шаг.
- **`HUMAN_TODO.md`.** Сюда агенты дописывают то, что нужно сделать человеку.
- Агенты могут вызывать субагентов для независимых подзадач.

| ID | Шаг | Без ключей и человека |
|----|-----|-----------------------|

| 07 | Отладка промпта на dev-задачах, заморозка | deferred |
| 08 | Основной прогон и прогоны под гипотезы | deferred |
| 09 | LLM-классификатор AI4I | deferred |
| 10 | Автопроверка, слепые листы, тарифы, `checks g2` | deferred (тарифы готовы) |
| **G2** | **Человек:** слепая проверка двумя людьми, сверка парсера и тарифов | мягкий гейт |

**Статусы шагов**
- `done` — шаг выполнен полностью.
- `deferred` — сделано всё, что можно без ключей или без человека. При следующем `run` шаг перезапустится и продолжит с того места, где остановился.
- `blocked` / `failed` — флоу остановлен, причина записана в handoff.

**Гейты** по умолчанию мягкие. Флоу сам запускает проверку гейта (`src.checks g1/g2`). Если проверка не проходит, флоу пишет, что осталось сделать, и идёт дальше. С флагом `--strict-gates` флоу на гейтах останавливается.

## Команды
```bash
python3 flow/flow.py status                 # где мы сейчас
python3 flow/flow.py run                    # пройти все невыполненные и отложенные шаги
python3 flow/flow.py run --mode interactive # интерактивные сессии: можно вмешиваться (выход из шага: /exit)
python3 flow/flow.py run --mode inline      # всё в текущем терминале, без новых окон
python3 flow/flow.py run --only 04          # перезапустить один шаг
python3 flow/flow.py approve G1             # отметить гейт (с проверкой; --force без неё)
python3 flow/flow.py reset 07 --yes         # сбросить состояние шага 07 и всех последующих (файлы проекта и git не трогаются)
python3 flow/flow.py prompt 05              # посмотреть промпт, который получит агент
```
Переменные окружения:
- `FLOW_MODEL`, `FLOW_EFFORT` — модель и уровень усилий;
- `FLOW_CLAUDE_ARGS` — дополнительные флаги `claude`, например `"--max-budget-usd 30"`.

## Как довести работу до конца
1. Первый `run` проходит шаги 01–12. После него готовы код, тесты, классическая часть типа E, черновик банка задач, ноутбук и каркас отчёта.
2. Выполните раздел G1 в `HUMAN_TODO.md` (ключи в `.env`, гипотезы, свои задачи, эталоны) и запустите `run`. Будут выполнены прогоны и подготовлены листы проверки.
3. Выполните раздел G2 (слепая проверка) и запустите `run`. Будут собраны анализ и каркас отчёта.
4. Выполните раздел G3: выводы и доклад.

## Файлы
- `flow/flow.py` — оркестратор (только стандартная библиотека Python).
- `flow/steps/*.md` — задания шагов.
- `flow/context/*.md` — handoff (коммитятся).
- `flow/state/` — служебное: промпты, коды выхода, отметки гейтов (не коммитится).
- `flow/logs/` — полные stream-json логи сессий (не коммитятся).
