## Пожелания
- **Локальная модель считается на домашнем сервере, а не на ноутбуке.** Сервер: `ssh home` (Linux, Tailscale 100.65.17.12, пользователь artemchernikov). На 10.10.2026 он offline в Tailscale; человек его поднимет. Ноутбук старый (M1 Pro, 16 ГБ), поэтому:
  - Полные прогоны локальной модели (банк, гипотезы, тип E) **на ноутбуке не запускать**. Допустимы только короткие проверки на 1–5 запросов.
  - Ближайший шаг, который выполняется (08, если он отложен — всё равно сделать): добавить поддержку удалённого Ollama.
    - `OLLAMA_BASE_URL` из `.env`: например, `http://100.65.17.12:11434` по Tailscale или `http://localhost:11434` через туннель `ssh -N -L 11434:localhost:11434 home`.
    - Замер памяти локальной модели при удалённом сервере брать из Ollama `/api/ps` (`size`, `size_vram`) или через `ssh home ps`, а не через psutil на ноутбуке.
    - Железо сервера (CPU, RAM, GPU) записывать в `results/run_manifest.json`: оно нужно для отчёта.
  - Если сервер доступен (`ssh -o ConnectTimeout=5 home true`), агент может сам установить и настроить на нём Ollama и `qwen3:8b`. Если недоступен, оставить скрипт `scripts/setup_home_server.sh` и пункт в HUMAN_TODO.
