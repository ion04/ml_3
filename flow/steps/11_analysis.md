# Цель
Ноутбук `analysis.ipynb`, из которого воспроизводится каждое число отчёта (шаг 9 хода работы).

# Предусловия и режимы
- Ноутбук пишется **сейчас в любом случае**. Он читает только `logs/`, `results/`, `grading/`, `config/`. С флагом `DEMO = True` в первой ячейке он читает `demo/`, и в каждом графике и таблице видна пометка «DEMO».
- Если реальных результатов или ручных оценок ещё нет, проверь ноутбук на demo-данных, сохрани его с `DEMO = False` без выполненных выходов и заверши шаг `deferred`.
- Если есть реальные данные и ручные оценки, выполни ноутбук полностью.

# Содержание ноутбука
1. Загрузка, объединение автопроверки и ручных оценок (деанонимизация по ключу), согласование двух проверяющих. По умолчанию берётся среднее двух оценок, расхождения выводятся списком.
2. Каппа Коэна для B, C, D (`sklearn.metrics.cohen_kappa_score`). Если κ < 0,6, выведи заметное предупреждение. Шаг тогда `blocked`: в HUMAN_TODO G2 добавь «уточнить рубрику и переоценить».
3. Точность по моделям, по типам и в разрезе «модель × тип»; доля отказов; два варианта точности при отказах (вопрос № 9).
4. Бутстреп 95% CI: 1000 ресэмплов задач, фиксированный seed.
5. Тест Макнемара (`statsmodels ... mcnemar(exact=True)`) для всех 6 пар моделей, дополнительно поправка Холма.
6. Тип D: pass@1, корректность, доля методологических ошибок по пунктам чек-листа.
7. Тип E: F1 по редкому классу и balanced accuracy в зависимости от числа примеров (0/5/20) для LLM и LogReg/NB (с разбросом по 20 наборам), константный бейзлайн.
8. Блок для каждой выбранной гипотезы: её метрика и тест. Бонусом, если данные есть: H10 (ECE по 5 корзинам и диаграмма надёжности) и H12. После каждого блока — ячейка «**Вывод (заполняет человек):** …». Вывод ты не пишешь.
9. Цена и скорость: средняя задержка, токены на задачу, ₽ за правильный ответ по `config/pricing.json`; для локальной модели — время и память.
10. Обязательные графики в `report/figures/`:
    - тепловая карта «модель × тип задачи»;
    - точность с доверительными интервалами;
    - «стоимость – точность»;
    - графики по гипотезам и по типу E.
11. Экспорт всех чисел в `results/summary_metrics.json`. Отчёт берёт числа только отсюда.
12. Проверка, что ноутбук выполняется чисто: `jupyter nbconvert --to notebook --execute --inplace analysis.ipynb` (в demo-режиме — во временную копию).

Код ноутбука должен быть простым и прокомментированным: студенту на защите объяснять каждую ячейку.
