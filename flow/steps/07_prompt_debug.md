# Цель
Отладить промпт и формат ответа на 5 dev-задачах на всех реальных моделях и заморозить их (шаг 5 хода работы).

# Предусловия
- Ключи для всех моделей, smoke-тест проходит.
- Если ключей нет (или есть не для всех моделей), отладь на доступных и заверши шаг `deferred`; в «Что нужно для завершения» перечисли, каких ключей не хватает. Ничего не подгоняй, если доступна только одна модель.

# Что сделать
1. `.venv/bin/python -m src.smoke_test`.
2. Прогони `data/tasks_dev.jsonl` через все модели с base-промптом, experiment `dev`. Посчитай для каждой модели parse_ok rate и соблюдение формата.
3. Если формат не соблюдается, поправь инструкцию формата так, чтобы она работала **для всех моделей**, а не для одной (вопрос самоконтроля № 10). Не больше 3 итераций. Каждая итерация получает новый `PROMPT_VERSION`, результаты итераций запиши в `docs/prompt_debug.md` (таблица модель × итерация). Если нужно, исправь парсер и добавь тесты.
4. Если среди гипотез есть варианты `cot` или `followup_doubt`, проверь их на 1–2 dev-задачах.
5. Банк оценочных задач (`data/tasks.jsonl`) не трогай и не прогоняй.
6. Заморозка: коммит `step 07: freeze prompt <version>`, версию промпта запиши в `config/experiment.json` → `prompt_version`.
