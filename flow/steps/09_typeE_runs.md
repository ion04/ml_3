# Цель
Прогон LLM-классификатора на AI4I 2020 (тип E).

# Предусловия
Ключи API и пройденный smoke-тест. Если их нет, проверь `--demo` и заверши шаг `deferred`. Для типа E не нужен коммит гипотез, но промпт должен быть заморожен на шаге 07. Если шаг 07 отложен, этот шаг тоже `deferred`.

# Что сделать
1. Пробный прогон на 20 строках для каждой модели и каждого режима (0/5/20). Проверь parse_ok; если формат ломается, это повод вернуться к шагу 07, а не подгонять промпт здесь.
2. Полный прогон на 200 строках.
3. Таблица `results/typeE_metrics.csv` для LLM и классических моделей: F1 по редкому классу, balanced accuracy, accuracy, константный бейзлайн, токены, задержка. Только числа, без выводов.
4. Коммит.
