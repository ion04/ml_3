# Цель
Основной прогон банка и дополнительные прогоны под выбранные гипотезы (шаги 6–7 хода работы), исполнение кода типа D.

# Предусловия
- `.venv/bin/python -m src.checks g1` проходит: ключи есть, гипотезы закоммичены, банк финализирован.
- Если проверка не проходит, **не запускай оценочные прогоны**. Порядок «гипотезы → прогоны» — требование задания. Проверь, что все скрипты готовы и работают в `--demo`, и заверши шаг `deferred` со списком невыполненных условий.

# Что сделать
1. Основной прогон: `src.run_bank --experiment main` для всех моделей и всех языков из `config/experiment.json`, T=0 или минимальная допустимая.
2. Прогоны `src.run_extra` для выбранных гипотез.
3. `src.exec_code` для ответов типа D.
4. Технические ошибки (сеть, 429, 5xx) дозапроси. Содержательно плохие ответы **не перезапрашивай**.
5. `results/run_manifest.json`:
   - даты прогонов;
   - `model_reported` для каждой модели;
   - версия промпта;
   - параметры;
   - число вызовов и ошибок;
   - хэш коммита гипотез.
   Обнови `pip freeze > requirements.txt`.
6. Сводка в handoff: только количества (сколько вызовов, сколько parse_ok). Без выводов о качестве моделей.
7. Коммит логов и результатов.
